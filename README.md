# Project Management API

### **🎯 Project Overview**

Design and build a **secure, scalable, and role-based backend API** for a **project management system**  using **Express.js** and **Mongoose**.

Your task is to implement a system where **Manager** can request rides, **Staff** can accept and complete rides, and **admins** can manage the overall system.

You must implement:

- 🔐 Authentication
- 🎭 Role-based Authorization
- 🧍 ADMIN | MANAGER | STAFF Logic
- 🚗 Project Management Logic
- 📦 Modular Code Architecture
- 🔁 Proper API Endpoints
